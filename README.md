## 📖 模组概述

**Lzxnone Terraria** 是一款面向 Minecraft NeoForge 的冒险战斗模组。模组忠实再现了《泰拉瑞亚》的经典战斗体系，并融入了《灾厄》（Calamity）模组的特色内容。

### ✨ 核心内容总览

- ⚔️ **职业与武器库**
  - **近战**：收录泰拉系列经典剑刃（如永夜刃、泰拉刃、天顶剑等）与特异武器，支持弹道剑气与挥砍特效；包含灾厄特色近战武器（如破灭魔王剑）及专属杀戮模式。
  - **魔法**：引入独立魔力值（Mana）系统、魔力水晶上限提升、魔力药水及耐魔性机制；包含终极棱镜、月耀等标志性法术武器与法师长袍。
  - **远程**：涵盖各阶段枪械、重火器与神弓，配备专属弹药库（叶绿弹追踪、灵液弹等）与狙击镜战术瞄准变焦系统。
  - **召唤**：支持仆从槽位上限管理，提供多节星尘巨龙、自律环绕飞剑（泰拉棱镜）及长鞭等召唤物与控制指令。

- 💍 **饰品体系 (Curios)**
  - 深度兼容 **Curios API**，还原十字章护盾合成树、各职业战斗徽章、天界贝壳、强化手套等丰富饰品与属性增益。

- 🔮 **专属机制与增强**
  - 包含多项围绕魔力、远程弹药与召唤物的专属附魔词条。
  - 采用原生着色器与粒子效果，并支持动态光源（如 LambDynamicLights）联动。

## ⌨️ 常用快捷键

可在游戏的按键控制菜单中自由配置：

- `C`：切换特异武器的**杀戮模式**
- `X`：遣散当前选中的仆从
- `Ctrl + X`：一键遣散所有在场仆从
- `V`：切换仆从的攻击/跟随模式

## 📦 前置依赖

运行本模组需要安装以下前置组件（请选择与您游戏版本对应的构件）：

- **Minecraft** 与对应版本的 **NeoForge**
- [Curios API (NeoForge)](https://www.curseforge.com/minecraft/mc-mods/curios-continuation)
- [LDLib2 (LowDragLib2)](https://github.com/Low-Drag-MC/LDLib2)

*可选兼容：推荐安装 [LambDynamicLights](https://github.com/LambdAurora/LambDynamicLights) 以获得武器光束与弹幕的动态发光效果。*
